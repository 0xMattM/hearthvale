# KayKit Adventurers (player avatars)

Same CC0 pack as **chessnoth-3d** (`Barbarian.glb`, `Rogue.glb`, etc.).

## Setup

1. Download **Free 2.0** from [KayKit Adventurers on itch.io](https://kaylousberg.itch.io/kaykit-adventurers)
2. Unzip
3. From repo root:

```bash
node scripts/setup-kaykit-avatars.mjs "C:\path\to\unzipped\Characters\gltf"
```

Until GLBs are copied here, avatars fall back to the procedural kit.
