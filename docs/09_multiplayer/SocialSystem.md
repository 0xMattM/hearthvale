# Purpose

The Social System defines the features that allow players to interact with each other.

The objective is to create a living community where players can:

- Communicate.
- Collaborate.
- Trade.
- Build relationships.
- Create organizations.

---

# Design Philosophy

## A World Built By Players

The game should encourage social interaction.

Players should not feel isolated.

The world should reward:

- Cooperation.
- Specialization.
- Trust.
- Community participation.
