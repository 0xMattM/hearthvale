# Purpose

The Character Design System defines the visual identity, customization, equipment representation, and progression appearance of player characters.

Each player controls one character that represents their journey inside the world.

The character should communicate:

- Player identity.
- Profession choices.
- Equipment progression.
- Achievements.
- Economic status.

---

# Design Philosophy

## One Character, Multiple Paths

Players do not create multiple characters.

One character can become:

- Farmer.
- Miner.
- Blacksmith.
- Hunter.
- Warrior.
- Merchant.
- Explorer.

The character evolves according to player decisions.

- Express identity.
- Avoid pay-to-win advantages.

# Final Statement

The character is the player's representation in the world.

A successful character system allows every player to create a unique identity while visually showing their profession, achievements, and journey.
