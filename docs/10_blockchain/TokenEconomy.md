# Purpose

The Token Economy System defines the monetary structure of the game.

The objective is to create a sustainable player-driven economy where:

- Players create value.
- Supply and demand determine prices.
- Production chains remain meaningful.
- Blockchain assets have utility.

---

# Design Philosophy

## Two Currency System

The game uses two different currencies.

```
Game Currency

+

Blockchain Token
```

Each one has a different purpose.

---

# Currency Overview

## Game Currency

Purpose:

Daily gameplay economy.

Used for:

- Marketplace transactions.
- NPC services.
- Basic purchases.
- Player trading.

---

## Blockchain Token

Purpose:

Long-term ecosystem value.

Used for:

- NFT-related activities.
- Special systems.
- Governance possibilities.
- External economy.

---

# Why Two Currencies

A single currency creates problems:

- Inflation affects everything.
- Speculation affects gameplay.
- New players become disadvantaged.

The two-currency model separates:

```
Gameplay Economy

from

External Value
```

# Currency Creation Rules

The game should minimize uncontrolled creation.

Currency should primarily circulate between players.

---

# Player-Driven Economy

Example:

```
Hunter

↓

Sells Leather

↓

Blacksmith Buys Materials

↓

Creates Armor

↓

Sells Armor
```

The value moves between players.

# Blockchain Token

The token represents ecosystem participation on **Creditcoin Testnet** (`REALM`). Players swap in-game coins for REALM through the Attestcoin Protocol. See [AttestcoinIntegration.md](AttestcoinIntegration.md).

# Token Utility

Possible uses:

- Land marketplace transactions.
- Special purchases.
- Ecosystem fees.
- Governance systems.

- Production success.

# Token Supply

# Token Emission Philosophy

Rewards should be based on:

- Contribution.
- Participation.
- Ecosystem growth.

---

# Energy Relationship

Energy limits production.

The purpose:

Prevent unlimited resource creation.

Flow:

```
Energy

↓

Production Capacity

↓

Resource Creation

↓

Economic Value
```

---

# Resource Economy

Resources should not directly create money.

Example:

Bad:

```
Mine Iron

↓

Receive Token
```

Good:

```
Mine Iron

↓

Create Item

↓

Sell Item

↓

Receive Currency
```

---

# Crafting Economy

Crafting creates economic value.

Example:

```
Miner

↓

Iron Ore

↓

Blacksmith

↓

Sword

↓

Warrior Buys Sword
```

# Market Dynamics

Prices are controlled by players.

Factors:

- Supply.
- Demand.
- Scarcity.
- Player behavior.

---

# Inflation Control

Main mechanisms:

---

## Production Limits

Energy limits activity.

---

## Item Consumption

Items should have sinks.

Examples:

- Durability.
- Repairs.
- Upgrades.

---

## Economic Sinks

Currency leaves through:

- Services.
- Fees.
- Special activities.

---

# Avoiding Pay-To-Win

Players should not be able to simply buy success.

NFT ownership and token usage should provide:

- Opportunities.

Not:

- Guaranteed victory.

---

# Token And Land Relationship

Land creates economic utility.

Example:

Land owner:

- Provides production space.

Players:

- Produce resources.

Economy grows.
