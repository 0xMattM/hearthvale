# Purpose

The Dungeon System defines challenging enclosed environments where players can explore, fight enemies, solve mechanics, and obtain valuable rewards.

The objective is to create memorable cooperative experiences focused on:

- Exploration.
- Combat.
- Strategy.
- Teamwork.
- Progression.

---

# Design Philosophy

## Dungeons Are Experiences, Not Rooms

A dungeon should provide:

```

+

+
```
