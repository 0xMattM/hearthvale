# Progression System

**Document Version:** 0.1.0  
**Status:** Work in Progress  
**Owner:** Gameplay Team  
**Last Updated:** July 30, 2026

---

# Purpose

The Progression System defines how players grow, unlock content, and develop their identity inside the world.

The objective is to create a long-term progression path based on:

- Player activity.
- Specialization.
- Mastery.
- Exploration.
- Contribution.

---

# Design Philosophy

## Progression Should Reflect Player Choices

Players should not all follow the same path.

The system should support different identities:

```
Explorer

+

Builder

+

Merchant

+

Crafter

+

Warrior

+

Leader
```

---

# Progression Layers

The player progression consists of multiple systems.

```
Character Level

+

Profession Level

+

Equipment Progression

+

Land Progression

+

Reputation Progression
```

---

# Character Level

Represents general player experience.

Increases through:

- Quests.
- Exploration.
- Combat.
- Production.
- Events.

---

# Experience System

Players earn experience from activities.

Example:

```
Complete Quest

↓

Gain Experience

↓

Increase Level

↓

Unlock Features
```

---

# Level Rewards

Each level can unlock:

- New abilities.
- New areas.
- New recipes.
- New systems.

---

# Level Requirements

Higher levels require:

- More experience.
- Greater challenges.
- Advanced activities.

---

# Level Philosophy

Levels should unlock possibilities, not simply increase numbers.

Example:

Bad:

```
Level 50 = More Damage
```

Better:

```
Level 50 = Access To New Profession Tier
```

---

# Profession Experience

# Profession Mastery

- Advanced recipes.

# Specialization System

```

+

+
```

# Horizontal Progression

After reaching maximum level, players continue through:

- New professions.
- New achievements.
- New discoveries.
- New specializations.

---

# Avoiding Infinite Power Growth

The system should avoid:

- Endless level inflation.
- Unbalanced players.
- New players being unable to compete.

---

- Seasonal rankings.
