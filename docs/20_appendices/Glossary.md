# Purpose

Shared vocabulary for design, engineering, and production. Prefer these terms in new docs.

---

# A–Z

| Term | Definition |
| --- | --- |
| **Blockchain Token** | On-chain currency for premium / NFT flows; does not replace soft currency gameplay. |
| **Crafting** | Transforming materials into higher-value items at a station. |
| **Energy** | Session-limited resource that gates actions and creates opportunity cost. |
| **Faucet** | System that introduces currency or items into the economy. |
| **Guild** | Player group for social and post-MVP territorial goals. |
| **Marketplace** | Player-driven price discovery venue. |
| **MVP** | Minimum playable vertical slice proving economy + trade + session progress. |
| **NFT Land** | Tradable land with production bonuses; never direct combat power. |
| **Opportunity Cost** | Value of the alternative action not taken (energy, land slot, time). |
| **Player-Driven Economy** | Markets and value primarily from player production and trade. |
| **Profession** | Optional specialization track (XP + efficiency); not a locked class. |
| **Production Chain** | Linked steps from raw resource to finished good. |
| **Sink** | System that removes currency or items from circulation. |
| **Soft Currency** | Off-chain gameplay currency earned and spent in normal loops. |
| **Specialization** | Higher efficiency in one activity versus a generalist. |
| **Starter Land** | Free, non-tradable land that guarantees full access to core systems. |
| **Territory War** | Structured PvP over public regions; personal lands stay safe. |
