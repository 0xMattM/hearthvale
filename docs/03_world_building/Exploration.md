# Purpose

The Exploration System defines how players discover and interact with the world.

The objective is to create meaningful exploration where players are rewarded for:

- Curiosity.
- Discovery.
- Risk-taking.
- Investigation.

---

# Design Philosophy

## Exploration Is A Core Gameplay Loop

Exploration should not be only movement between objectives.

The player should constantly find:

```
New Locations

+

Resources

+

Stories

+

Challenges

+

Rewards
```
