# Purpose

The Biome Catalog defines all environmental regions that exist in the game world.

The objective is to create structured data for:

- World generation.
- Exploration.
- Creature distribution.
- Resource placement.
- Settlement design.
- Environmental storytelling.

---

# Biome Philosophy

## Biomes Define The Identity Of The World

Every biome should provide:

```
A Unique Environment

+
```
