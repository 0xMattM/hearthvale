# Purpose

The Weapon Catalog defines all weapon types and their properties.

The objective is to create a consistent structure for:

- Combat progression.
- Equipment balance.
- Crafting.
- Loot generation.
- Trading.
- Legendary items.

# Weapon Philosophy
