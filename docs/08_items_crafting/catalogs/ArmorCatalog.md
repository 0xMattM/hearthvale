# Purpose

The Armor Catalog defines all defensive equipment available in the game.

The objective is to create a structured system for:

- Character customization.
- Combat progression.
- Defense balancing.
- Crafting.
- Loot generation.
- Trading.

---

# Armor Philosophy

## Armor Defines Playstyle

Armor should not only increase defense.

It should provide:

