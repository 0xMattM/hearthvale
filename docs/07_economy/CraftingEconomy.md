# Purpose

The Crafting Economy defines how crafting activities interact with the overall game economy.

The objective is to create a system where:

- Resources have value.
- Crafters have meaningful professions.
- Items maintain economic importance.
- Players depend on each other.
- Production creates sustainable markets.

---
