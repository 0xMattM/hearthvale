# Currency System

**Document Version:** 0.1.0  
**Status:** Work in Progress  
**Owner:** Economy Design Team  
**Last Updated:** July 30, 2026

---

# Purpose

The Currency System defines all monetary assets used within the game economy.

The objective is to create a balanced monetary structure that supports:

- Player progression.
- Trading.
- Crafting.
- Services.
- Digital economy integration.

---

# Currency Philosophy

## Currency Should Facilitate Value Exchange

Currency exists to enable:

```
Trade

+

Progression

+

Services

+

Economic Interaction
```

Currency itself should not be the main objective.
